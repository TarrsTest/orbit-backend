# evalkit

A tiny CommonJS utility kit with no dependencies. Run a test file with
`node --test test/<name>.test.js`.

| Module | What it does |
|---|---|
| `src/slugify.js` | URL slugs from titles |
| `src/paginate.js` | one page of a list |
| `src/array.js` | array helpers |
| `src/duration.js` | parse `1h30m`-style durations |
| `src/pricing.js` | order totals with discounts |
| `src/config.js` | runtime flags |
| `src/retry.js` | retry an async function |
| `src/users.js` | user lookups |
| `src/csv.js` | parse one CSV line |
| `src/lru.js` | a least-recently-used cache |
| `src/semver.js` | compare version strings |
| `bin/wc.js` | count words in a file |
